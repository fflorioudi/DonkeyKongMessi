# QA V3.2.1 - Frecuencia Variable De Pelotas

## Objetivo

Reemplazar el ritmo fijo de pelotas por una frecuencia variable en milisegundos, dejando el limite de activas como seguro tecnico.

## Cambio

- Primera pelota: `1200 ms`.
- Siguientes pelotas: rango aleatorio entre `2200 ms` y `4200 ms`.
- `maxActive` de pelota: `8`, solo para evitar acumulacion extrema.
- Tarjeta roja conserva su ritmo fijo por ahora.

Ejecutar:

```bash
npm run qa:v3.2.1
npm run qa:v3.2
npm run qa:v3.1
npm run qa:v2.1
npm run typecheck

```

Validaciones cubiertas por `qa:v3.2.1`:

- `ObstacleSpawnerDefinition` acepta `spawnDelayMs`.
- El spawner de pelotas declara rango `2200-4200 ms`.
- El motor usa helper para delay inicial y siguiente delay.
- La seleccion aleatoria mantiene fallback a `interval`.
- La portada declara `Mobile v3.2.1`.

## QA Manual Mobile

1. Iniciar partida.
2. Esperar la primera pelota.
3. Confirmar que las siguientes no salen con ritmo perfectamente fijo.
4. Subir por el mapa vertical.
5. Confirmar que el peligro se siente mas organico pero no injusto.
6. Confirmar que al respawnear no quedan pelotas acumuladas abajo.

## Criterio De Cierre

- La frecuencia se siente viva.
- No hay lluvia absurda de pelotas.
- El tutorial sigue siendo ganable.
- La camara V3.2 no se ve afectada.
