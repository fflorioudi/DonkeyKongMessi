# QA V3.4.2

Objetivo: cerrar el ajuste de tutorial visual, reforzar controles tactiles y sumar a Ronaldinho como invencibilidad de un solo uso en Nivel 1.

## Checklist Automatico

- `npm run assets:level0`
- `npm run qa:v3.4.2`
- `npm run qa:v3.4.1`
- `npm run qa:v3.4`
- `npm run qa:v3.2.2`
- `npm run typecheck`
- `npm run lint`
- `npm run build`

## Validaciones Visuales

- La cover del Tutorial aparece en el selector de niveles.
- El Tutorial usa fondo de Rosario y plataformas nuevas.
- Las plataformas del Tutorial no muestran bloques de color plano si el spritesheet carga.
- Los controles jugables no aparecen en portada ni selector.

## Validaciones De Juego

- Al soltar izquierda o derecha, Messi se detiene.
- Si el dedo sale del boton, se limpia la direccion.
- Si se cambia de app, se bloquea pantalla, se pausa o se pierde foco, el input queda reseteado.
- En Nivel 1, Ronaldinho aparece lejos del Botin de Oro.
- Ronaldinho se toma una sola vez, desaparece y da invencibilidad temporal.
- El Botin de Oro conserva su comportamiento anterior.
- Los obstaculos de Nivel 1 siguen siendo pelota y tarjeta roja.
