# QA V3.4.6

## Alcance

- Integracion jugable inicial del Nivel 2.
- Cover del Nivel 2 disponible en seleccion de niveles.
- Escudo de invencibilidad y Neymar como asistencia de un solo uso.
- Pinches fijos como sprites de pixel art, sin cuadrados de fallback.
- Messi del Nivel 1 reutilizado en el Nivel 2.

## Comandos

```bash
npm run assets:level2
npm run qa:v3.4.6
npm run qa:v3.4.5
npm run typecheck
npm run lint
npm run build
```

## Criterios

- `level2Shield`, `level2Companion` y `level2Hazards` existen en `public/sprites/sprites.json`.
- El selector muestra Nivel 2 como jugable con `/assets/levels/level-2-cover.png`.
- El Nivel 2 declara `level1Messi`, `level2Rival`, `level2Platforms`, `level2Shield`, `level2Companion` y `level2Hazards`.
- Los pinches se comportan como obstaculos fijos y no disparan audio de lanzamiento.
