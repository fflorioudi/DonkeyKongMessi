# QA V3.4.1 - Messi Y Cover Nivel 1

## Objetivo

Completar la identidad visual del Nivel 1 sin cambiar sus obstaculos.

## Assets Nuevos

- `public/sprites/level-1-messi.png`
- `public/sprites/source/level-1-messi-source.png`
- `public/assets/levels/level-1-cover.png`

## Decision De Jugabilidad

Los obstaculos de Nivel 1 siguen siendo los mismos:

- Pelota.
- Tarjeta roja.

No se agregan obstaculos nuevos en esta version.

## QA Automatico

Ejecutar:

```bash
npm run assets:level1
npm run qa:v3.4.1
npm run qa:v3.4
npm run typecheck
npm run lint
npm run build
```

## QA Manual

1. Abrir selector desde `Jugar`.
2. Confirmar que Nivel 1 usa la cover nueva.
3. Entrar a Nivel 1.
4. Confirmar que Messi usa camiseta Barcelona.
5. Confirmar que Tutorial mantiene el Messi anterior.
6. Confirmar que los obstaculos siguen siendo pelota y tarjeta roja.
