# QA V3.2.3 - Portada Nueva Y Prologo De Historia

## Objetivo

Activar la portada nueva como pantalla principal sin duplicar botones, y dejar claro que el mapa actual es el tutorial previo a los cinco niveles.

## Cambio

- Portada activa: `public/assets/cover-chatgpt-escalada-del-10.png`.
- Botones visibles provienen del arte.
- Botones reales invisibles quedan superpuestos como hotspots accesibles.
- El boton `Audio` de portada ejecuta prueba de sonido.
- El boton superior de mute se oculta en menu para no duplicar controles.
- El tutorial muestra etiqueta propia en HUD.
- Entrenar abre un prologo con el camino: Tutorial + Nivel 1 a Nivel 5.

## QA Manual Mobile

1. Abrir la portada.
2. Confirmar que no hay titulo ni botones duplicados encima del arte.
3. Tocar `JUGAR` en la imagen y confirmar que inicia el tutorial.
4. Volver al menu.
5. Tocar `ENTRENAR` y confirmar que abre el prologo.
6. Confirmar que el prologo lista Tutorial + Nivel 1 a Nivel 5.
7. Tocar `AUDIO` en la imagen y confirmar que suena.
8. Iniciar partida y confirmar que el HUD muestra `Tutorial`.

## Criterio De Cierre

- La portada se siente como una pantalla final, no como una imagen tapada.
- Los botones del arte son realmente clickeables.
- El tutorial queda separado narrativamente de los cinco niveles futuros.
- El juego sigue arrancando sin pasos extra.
