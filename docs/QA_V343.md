# QA V3.4.3

Objetivo: integrar carteles de pausa/victoria y corregir la jugabilidad tactil que impedia moverse bien en el aire.

## Checklist Automatico

- `npm run qa:v3.4.3`
- `npm run qa:v3.4.2`
- `npm run qa:v3.2.2`
- `npm run typecheck`
- `npm run lint`
- `npm run build`

## Validaciones De Pausa

- El cartel de pausa usa `public/assets/ui/cartel-pausa.png`.
- Los botones embebidos funcionan como hotspots:
  - Seguir: vuelve a la partida.
  - Reiniciar: reinicia el nivel actual.
  - Inicio: vuelve al menu.

## Validaciones De Victoria

- Tutorial usa `public/assets/ui/final-level-0.png`.
- Nivel 1 usa `public/assets/ui/final-level-1.png`.
- Tiempo, puntuacion de la run y mejor puntuacion se renderizan sobre el cartel.
- En Tutorial, `Siguiente nivel` abre Nivel 1.
- En Nivel 1, `Siguiente nivel` queda deshabilitado hasta que exista Nivel 2.
- `Jugar de nuevo` e `Inicio` siguen funcionando.

## Validaciones De Jugabilidad

- Messi puede saltar y seguir moviendose en el aire.
- Soltar salto no cancela izquierda/derecha si el dedo de movimiento sigue presionado.
- El fix anti-direccion pegada conserva `pointercancel`, `touchcancel`, `blur` y `visibilitychange`.
- En Tutorial, los pies de Messi quedan alineados con la superficie de las plataformas nuevas.
